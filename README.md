# Portfolio Frontend

A React single-page application for presenting portfolio content, including home, projects, and contact pages.

## Tech Stack

- React 18
- React Router
- Bootstrap 5
- Font Awesome

## Getting Started

1. Install dependencies:
   - `npm install`
2. Start the development server:
   - `npm start`
3. Build for production:
   - `npm run build`
4. Run tests:
   - `npm test -- --watchAll=false`
